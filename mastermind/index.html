Mastermind

Salon

Trouve le code secret de couleurs : à chaque essai, des fiches te disent combien de couleurs sont bien placées (noir) ou présentes mais mal placées (blanc).

Course : tout le monde cherche le même code, le moins d'essais gagne. Duel : à deux, chacun cache un code à l'autre. Un joueur crée le salon, les autres entrent le code à 4 lettres.

Réglages de la partie (pour celui qui la crée)

En attente des joueurs

Donne ce code aux autres :

      Mastermind

      Un code secret de 4 (ou 5) couleurs est caché. Trouve-le en un minimum d'essais.

      Jouer

      • Touche les couleurs pour remplir ta rangée (touche un pion de la rangée pour l'enlever), puis valide.
      • Pour chaque essai, des fiches s'affichent à côté : une noire pour chaque couleur bien placée, une blanche pour chaque couleur présente dans le code mais mal placée. Les fiches ne disent pas lesquelles !
      • Si les couleurs répétées sont permises, une couleur peut apparaître plusieurs fois dans le code.

      Les modes

      • Seul : trouve le code de l'ordinateur.
      • Course : tout le monde cherche le même code ; celui qui le trouve en moins d'essais gagne (égalité possible). Le temps ne sert qu'à départager l'ordre du classement.
      • Duel : chacun cache un code à l'autre ; celui qui trouve le code adverse en moins d'essais gagne. Tu vois en direct les essais de l'autre sur ton code.
      • Les bots jouent leur essai suivant quand tu as joué le tien.
